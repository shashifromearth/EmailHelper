Job applier settings

EH_API_TOKEN from .env (or data/api-token.txt). Used for the agent and the knowledge service. JOB_LINKS_TOKEN from .env. Only if the knowledge service uses its own token. Empty: the API token. Submit automatically on employer career sites when every required field is filled and nothing needs you. When stuck it asks you on Telegram. Job boards (LinkedIn, Naukri, Glassdoor, Wellfound, Indeed) are never submitted; with this on and no platforms set, they stay queued. Only apply for this person's jobs (an id from knowledge/people.json). Empty: any. Only take jobs from these sites. Empty: any.
