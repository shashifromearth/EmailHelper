====================================================
PRODUCT GOAL
====================================================

Build a local-first AI-powered Thunderbird assistant capable of:

1. Detecting new incoming emails.
2. Reading email contents.
3. Preventing duplicate processing.
4. Classifying emails.
5. Retrieving contextual information.
6. Generating reply drafts.
7. Validating generated responses.
8. Saving replies as Thunderbird drafts.
9. Never sending emails automatically.
10. Notifying the user using Telegram.
11. Running entirely locally by default.
12. Supporting optional remote LLM providers.
13. Supporting multiple mail accounts.
14. Maintaining audit history.
15. Supporting extensible future agents.
