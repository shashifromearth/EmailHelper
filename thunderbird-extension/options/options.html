EmailHelper settings

Backend

Only http://127.0.0.1 or http://localhost (any port) are allowed.

Behaviour

Accounts

New mail is only sent to the backend for checked accounts. The account type is inferred from the account's e-mail domain; override it if it is wrong (for example Google Workspace on a custom domain).

EnabledAccountProtocolType

Existing mail

Queue the unread messages already in the Inbox of every enabled account (up to 200 per account). Messages already handed to the backend are skipped.
